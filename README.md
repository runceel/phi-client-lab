# PHI for Windows 11

[wphiのプロトコル・動作仕様](https://github.com/s7k/wphi/blob/main/docs/04-client-spec.md)を
基に実装した、C# / WinUI 3のPHIクライアントです。UIにはMicrosoft公式の実験的な
[Microsoft.UI.Reactor](https://github.com/microsoft/microsoft-ui-reactor)
NuGetパッケージ（`0.1.0-preview.17`）を使用しています。
MauiReactorや同名の自作ライブラリによる代替ではありません。
既存データとの互換性のため、内部プロジェクト名の`PhiClient`、パッケージidentity、
設定の保存先と資格情報キーは変更していません。
主要機能を実装し、wphiとの互換性と実UIの確認を進めています。**全機能の互換性確認は完了していません。**
現在の統合は初期実装の区切りです。native入力・実操作の未確認と、試験前の表示設定4値を
復旧できていない問題を残しており、統合後の個別Issueでの追跡と区別します。
56項目の実装箇所・確認結果・残確認は[互換性照合記録](docs/wphi-compatibility.md)を参照してください。

## 開発環境と起動

- Windows 11。開発用パッケージの登録には開発者モードを使います。
- .NET 11 SDKとWinApp CLI 0.7以降（開発時は0.8.0）。
- x64またはARM64。single-project MSIXのpackaged構成です。
  起動エラーの回避を目的としたEXEの直接実行やunpackaged構成への変更は行わないでください。
- 初回のNuGet復元とWindows App Runtimeのセットアップにはインターネット接続が必要です。

リポジトリのルートでPowerShellを開き、実行します。

```powershell
dotnet build .\PhiClient\PhiClient.csproj -p:Platform=x64
winapp run .\PhiClient\PhiClient.csproj --arch x64 --detach
dotnet test .\PhiClient.Core.Tests\PhiClient.Core.Tests.csproj
```

ARM64では、ビルドの`x64`を`ARM64`、`--arch`を`arm64`へ変更します。
Native AOTの発行設定・動作確認は行っていません。公式テンプレートの.NET 11 Windowsターゲットを
使用し、対応するWindows App SDKをReactor経由で参照します。
WinUI analyzerは`PrivateAssets=all`でアプリだけに適用します。

深いパスやアクセス制限のあるcheckoutからパッケージを登録できない場合は、
AppData外の短いパスを、構成ごとの配置先に指定します。

```powershell
winapp run .\PhiClient\PhiClient.csproj --arch x64 --detach `
  --output-appx-directory "$env:USERPROFILE\PhiClientLayouts\Debug-x64"
```

MSIX版WinApp CLIではAppData内への書き込みが転送されるため、その配置先を登録できません。
開発用パッケージは配置先フォルダーを参照し続けます。起動後もフォルダーを保持し、
ビルド構成・CPUアーキテクチャごとに分けてください。
登録エラーの回避を目的としたpackagingの無効化やシステムACLの変更は行わないでください。

### GitHub Copilotアプリから手動起動する

`.github\github-app.yml` を確認・承認すると、スクリプト一覧に **Start PHI for Windows 11 (WinUI)** が表示されます。
選ぶと `tools\Start-PhiClient.ps1` がpackaged x64をビルド・起動します。
自動実行triggerとゲームへの自動接続は追加していません。Windows、PowerShell 7.4以降、
.NET 11 SDK、WinApp CLIが必要で、WinApp 0.8.0で確認しています。
初回は通常の依存復元・開発用パッケージ登録が必要です。OS設定や管理者権限の変更は自動化しません。

作業フォルダーごとの `--unique-identity` を使い、通常の製品identityの登録・設定とは分けます。
この起動先へ通常製品の登録が自動コピーされることはありません。同じ作業フォルダーでのデータは保持し、
設定の初期化や既存appの強制終了は行いません。
layoutはAppDataを避けた `%USERPROFILE%\PhiClientLayouts\<作業フォルダーのハッシュ>\Debug-x64` に置きます。
作業フォルダー・CPU別に分け、起動後も削除しないでください。共有設定へユーザー固有の絶対パスは埋めていません。

起動せずにコマンドを確認する場合と、ARM64/ビルド済み出力を使う場合は次のとおりです。

```powershell
.\tools\Start-PhiClient.ps1 -WhatIf
.\tools\Start-PhiClient.ps1 -Architecture arm64
.\tools\Start-PhiClient.ps1 -NoBuild
```

`COPILOT_WORKSPACE_PATH` が設定されている場合はスクリプトのworktreeと一致することを確認し、
異なる場合は明示的に停止します。`GH_TOKEN` 等の環境変数を表示・保存しません。

トリミングを有効にしたRelease発行では、通常の復元を含めて実行します。

```powershell
dotnet publish .\PhiClient\PhiClient.csproj -c Release -p:Platform=x64
```

Debugだけの復元にはRelease用のlinker/crossgenツールが含まれないため、
その状態で`--no-restore`を指定しないでください。build出力とpublish出力を切り替える場合は、
新しい配置先を使います。発行フォルダーを直接登録する場合は、Windows App Runtimeへの依存を含む
MSBuild生成の`AppxManifest.xml`を指定します。展開前の`Package.appxmanifest`は使いません。
トリミングしたパッケージの起動は、ビルド成功とは別に確認が必要です。

## 主画面と登録

通常は **マップ＋チャット** を表示します。32 DIPのnativeタイトルバーの左上に、
**メニュー・操作ガイド・内緒話** をアイコンでまとめました。操作名はTooltipと読み上げ名で確認できます。
内緒話の未読会話数と接続状態も左側に残し、狭幅では接続状態を短い表記とTooltipで示します。
タイトルはWindowsのcaptionボタンを含む窓全体の中央に置き、左右に重ならない幅で末尾を省略します。
タイトルの上もドラッグ領域です。登録フロー中は従来どおり補助操作を表示しません。
最小化・最大化・閉じるはWindows標準のcaptionを使い、独自の疑似ボタンは作っていません。
タイトルバーの中央位置と補助操作は、旧表示名「PHI Client」で150% DPI・ダークテーマの通常幅、登録画面、
未接続のゲーム画面で確認しました。標準captionによる最大化・復元も確認しています。
狭幅の省略・重なり、実ドラッグ・Snap、実キー、ライト・ハイコントラスト、DPI切り替えは確認保留です。
正式名「PHI for Windows 11」も、150% DPI・ダークテーマの通常幅で窓全体の中央に表示され、
左のメニュー・右の標準captionと重ならないことを確認しました。狭幅のnative確認は操作が完了せず保留です。
以下のFile / Character / View / Help等は、タイトルバーの **メニュー** 内にあります。
Helpの **wphiの利用者ガイド（ブラウザー）** から、原典の画像付きガイドを参照できます。
確認画面で承認した場合だけ外部ブラウザーを開きます。wphi向けの説明のため、
このWinUI版の画面配置・Tabモード切替・送信後の入力消去などは本READMEを優先してください。
操作ガイドと操作パッドは通常は非表示です。既に保存済みのパッド表示設定は変更しません。
狭幅では地図とログを上下に並べ、内緒話は世界の会話と切り替えて表示します。

**キャラクターを新規作成する** は専用の **世界→キャラクター→確認** の3段階です。
世界の選択だけでは通信しません。候補の取得は明示操作で行い、取得中も登録を中止できます。
確認画面の **この世界に作成する** を押して初めて作成要求と、自動生成を選んだ場合の秘密値を生成します。
結果が不明なら再送せず、作成成功後にPCへの保存だけ失敗した場合は同じID・パスワードを保持して
**PCに保存し直す** だけを行います。保存後も自動接続しません。
**既存のキャラクターIDを登録する** は別の1画面で、ローカル保存だけを行います。

## 設定

**File > 設定…** から編集し、**設定を保存** でこのPCの `settings.json` に保存します。
閉じると未保存の変更を破棄します。Philly.iniの取り込みは編集画面に反映するだけで、
保存・接続・キャラクターIDの取り込みは行いません。キーは原典と同じ大文字小文字で解釈し、
重複項目は先頭を採用します。

F8–F12は通常時とリスト表示中で別の送信文字列を設定でき、`\n` は改行として送ります。
Alt+Gとフルキー移動も設定できます。自動装備を有効にすると、原典と同じ対象選択のない
系統魔法だけ、実際に外した1番の武器を名前で装備し直します。detectなどの対象選択魔法では
装備し直しません。自動装備・武器を外す操作はそれぞれ無効にできます。

設定の保存・キー・自動装備・マップ倍率・拡張マップ・滑らかな移動は実装済みです。
通常のボタンやログにフォーカスがある間も、ゲーム操作キーを使います。
ただしボタン・チェックボックスのSpace/Enter、選択UIの矢印などはnative操作を優先します。
チャット・priv・看板・登録・設定などの編集欄、IME変換中、確認画面、メニュー、
地図幅の境界操作は、それぞれの入力を優先します。ログのCtrl+C / Ctrl+A / Ctrl+Insertも維持します。
主画面のTabは **チャット入力欄⇔ログ欄** のモード切替です。ログ側では移動・行動キーを使い、
チャットへ戻っても下書きを保持します。Escでもログへ戻れます。
Shift+Tabは通常のUIフォーカス移動に使えます。設定・登録・priv・モーダル等のTab順は変更しません。
ログのリンクやスクロールバー等のnative操作も維持します。実キーと日本語IMEの確認は引き続き保留しています。
ログの時刻・フォント・行コピー、効果音・通知の設定も適用します。
**Operation > ログを検索** または世界ログ・チャット欄の **Ctrl+F** で、選択中のキャラクターの
保持済みログを検索します。大文字・小文字を区別せず、最初は最新の一致行へ移動します。
検索欄の **Enter / Shift+Enter** または矢印ボタンで古い／新しい一致行へ循環し、
現在位置と件数を表示します。検索中は新着への追随を抑止し、**Esc / ×** で閉じるとログへ戻ります。
実際の強調位置・スクロール・キーとIMEのnative確認は未完了です。
**マップをログと同じ窓に表示する** を有効にすると統合表示、無効にすると独立した地図窓を使います。
切り替えても接続と地図の状態を保持し、表示中のキャラクターに追従します。
地図の **− / 倍率入力欄 / ＋** で50–400%の整数倍率を指定できます。
−/＋は25ポイントずつ変更し、**100%に戻す** で復帰します。
通常地図とEagleEyeの両方に適用し、倍率を保存します。大きな地図は縦横にスクロールできます。
地図画像の比率を保ち、補助情報・素材の状態・方位図・PNG保存は **地図情報・保存** にまとめました。
**View > 操作パッドを表示** は非表示中も使え、表示状態を保存します。設定画面からも変更できます。
パッドは3×3の位置関係で、上段が左旋回・北/前・右旋回、中段が西/左・攻撃・東/右、
下段は中央だけ南/後です。下の両隅は空欄です。斜め移動を新設せず、既存の7操作を配置しています。
中央の攻撃はSpace相当で、NumPad5ではありません。
地図窓だけを閉じると非表示になり、**View > Map pane** またはShift+F5で再表示します。
メイン窓と地図窓の位置・大きさ・最大化状態は公式Reactorのpackaged保存機能で復帰します。
モニター構成が変わった場合は保存位置を使わず既定の配置へ戻します。
統合表示では地図とログの境界をドラッグして地図の幅を変え、操作完了時に保存します。
境界にフォーカスを移すと左右キーで16 DIPずつ、Home/Endで調整範囲の端まで変更できます。
幅は200–1600 DIPの範囲で、ログ用の領域を残すよう現在の窓幅に合わせます。
窓を狭くしても保存した希望幅を保ち、広げるとその幅へ戻します。
この変更・保存経路とログの範囲選択保持はnative UIAで確認済みです。
物理ドラッグと実キーによる確認は保留しています。
全画面・全操作の実UI確認は、互換性監査の後続作業です。

### 版情報・更新確認・時刻の記録

**Help > バージョン情報** に、このアプリのpackaged版を表示します。
**Help > 新しい版を確認する…** を選ぶと、`runceel/phi-client-lab` の公開GitHub Releasesを確認します。
起動時には取得せず、wphi本体の版や配布ファイルをこのアプリの更新として扱いません。
公開リリースがまだない場合と、取得に失敗した場合を分けて表示します。
新しい版があれば、確認後にこのリポジトリのHTTPSリリースページを開きます。

**Help > 時刻の記録を開始する** は、不具合調査用に操作・受信・地図更新の時刻と
イベントの種類だけを `Logs\trace-*.txt` へ保存します。発言本文・ID・パスワード・
接続先は記録しません。停止、正常終了、100000件の上限で記録を終え、
書き込みの問題は保存済みのファイルを保持して知らせます。
**Help > 窓の位置を元に戻す…** は、確認後にメイン窓と地図窓を現在の画面へ配置し直します。
接続・登録・設定項目は保持します。

### 効果音と通知

設定の **効果音を使うPhillyフォルダー** に、このPCにあるPhillyフォルダーの絶対パスを入力します。
`Config\SoundRegexp.ini` と `SoundFile.ini` をCP932で読み、先頭の説明行を除いて同じ行番号の
規則とWAVを対応させます。最初に一致した規則を使い、相対WAVパスはそのPhillyフォルダーから
解決します。WAV欄が空の規則はタスクバー通知です。空欄のフォルダーを保存すると規則を解除します。
効果音の素材・音声は同梱せず、利用条件に従ってユーザーが用意したローカルファイルを使用します。

発言・privは、背面時だけタスクバーで知らせます。大声と既定のDM／接続者数の行は除外し、
`Config\NotFlashRegexp.ini` がある場合はその規則を使います。`#more` の本文では効果音・通知を
実行しません。壊れた規則は元の行番号を知らせ、WAVの対応をずらしません。再生失敗はログへ
表示し、設定を保存するとその規則を再試行します。

読み込みはネットワーク共有・リンクを含むパスを対象外とし、設定1MiB、規則4096文字、
照合50ms、WAV16MiB、同時再生16件に制限します。これらは原典との差異となる安全制限です。
純粋な規則／CP932の試験とモック受信からのnative再生エラー表示を確認しています。
正常なWAVの実音出力と前面・背面切り替え時の目視確認は、残る実UI確認です。

## 拡張マップと位置予測

旧5×5マップは地形とアイテム／看板の別平面を読み込み、変更なしの `#map M -` では
向き・地形・actorを保持します。actorは原典と同じ `#m57 O/W` の有効な行を受けて初めて
一覧を置き換えます。CR/LF付きの変更なし行も同じ扱いです。

絶対座標を送る世界の7×7北固定マップだけを、世界別に記録します。未知のマスと盲目中の
地形は記録せず、記録した外周や視界外の補完部分を25%暗く表示します。窓のマップ欄と倍率に
合わせて外周を最大4マス追加します。記録は `Maps` フォルダーへ32×32マスの区画単位で
約5秒ごとに保存します。異常なファイルは上書きせず、読み込み・保存の失敗を知らせます。
**View > 現在の世界の記録地図を消す…** は確認後にその世界だけを消します。

「拡張マップ」が有効なら、送った北固定の `go N/E/S/W` の返事を120–1000ms待ってから
表示上の位置を予測します。待ち時間は直近8件の遅延に合わせ、予測は100msより速く進めません。
サーバーの座標・移動失敗・世界移動で補正し、追加の移動命令は送信しません。
最後に受信した7×7地形は予測時にも保持します。

滑らかな移動は原典と同じ実験的な90msの表示処理です。同じ世界で2マス以内の北固定移動に
限り有効で、世界変更・大きな座標変更では使いません。Windowsでアニメーションを無効に
している場合も使いません。描画は整数ピクセル・最近傍を使い、クリック座標も倍率に合わせます。
非常に高いDPIと倍率の組み合わせで4096pxの描画上限に達した場合は、倍率を下げる案内を表示します。

## 地図画像の保存

地図欄の **地図情報・保存 > 表示中の地図をPNGに保存** を押すと、
マップチップ・キャラクター画像・名前ラベルをまとめて保存できます。
EagleEyeを表示中はその地図を保存します。画像はこのPCのアプリデータ内の `MapImages`
フォルダーに保存し、**地図画像の保存先を開く** から確認できます。
保存名は日時とランダムな識別子で作り、キャラクターIDを含めません。画像の保存による
ゲーム命令の送信はありません。素材の利用・共有には、取り込んだ素材の利用条件が適用されます。

## ゲームの操作

**Operation > 全タブへ発言** は、開いている接続中のタブだけへ同じ行を送ります。
送信ごとに対象タブ数を確認し、キャンセルすると全タブ発言を解除して下書きを保持します。
保存済みのキャラクターを新たに開く操作ではありません。

**Operation > 大声で発言** は世界全体への発言です。確認画面の **今回だけ送信** は
送信後に通常発言へ戻し、**すべて大声** は次の発言にも適用します。
全タブ発言を有効にしている間は通常発言として送ります。
**発言の前に付ける言葉…** は空の入力行と送信後の新しい行へ追加します。空欄で解除できます。
末尾行で修飾キーを使わずDownを押すと、その行を設定した言葉に置き換えます。
IME変換中はこの操作を行いません。

発言欄と看板欄は右クリック、または **タグ…** から選択範囲を原典の色・サイズ・スタイル・
フォントタグで囲めます。選択が空ならその位置に挿入します。Customとフォントは値を入力する
位置へカーソルを戻し、完成したタグは閉じタグの後ろへ戻します。
切り取り・コピー・貼り付けなどの通常編集も同じメニューから使えます。タグの挿入だけでは送信しません。
原典の根拠は `ui\src\tagMenu.ts` と `TagMenuPopup.tsx` です。

これらの状態遷移・行編集・100msの送信間隔は純粋テストで確認しています。
所有モック2タブのnative UIAで、全タブ発言の取消・送信、大声の今回／継続、発言prefix、
通常全切断・全再接続・全強制切断を確認しています。
実キーとIMEは前面化が可能になってから行う残確認です。

1. 既存のキャラクターは表示名、接続先、TCPポート、IDを入力して **キャラクターを保存** で保存します。
   **Phillyの登録を取り込む…** はPhillyフォルダー直下の `表示名.chara\.phirc` を読み込みます。
   `.Chara` も対象です。原典と同じCP932の1行目をID、2行目を `ホスト:ポート` または
   `ホスト ポート` として扱い、表示名を順序付きで取り込みます。
   確認後に同じ表示名の登録を置き換え、IDをWindowsの資格情報、接続先を `characters.json` に
   保存します。別の表示名の登録と元のPhillyファイルは保持します。
   読み取りに問題のあるファイルは件数を表示し、有効な登録だけを取り込みます。
   同じ表示名のタブは閉じてから取り込んでください。取り込み後の接続はキャラクターの選択で行います。
   1ファイル64 KiB・一度に1000件までとし、ローカルの通常フォルダーを対象にします。
   原典の根拠は `src-tauri\src\characters.rs:138–175` です。
2. 新規作成では **キャラクター画像の一覧を取得** で、その世界が返す初期画像の一覧を取得できます。
   原典と同じ `#ex-get REGINFO IMG` を送り、`#ex-put REGINFO IMG` から `#ex-put .` までを
   0番から順番に表示します。この操作は指定したゲームサーバーへTCP接続しますが、
   ID・パスワード・作成要求は送りません。起動時や世界選択時の自動取得は行いません。
   一覧で選ぶか番号を入力すると、設定した実wphi素材の正面・大きい絵・コマ0を表示します。
   素材がない場合はその理由を表示し、別のキャラグラで代用しません。
   サーバーまたはポートを変えると候補を破棄し、古い取得結果も適用しません。
   候補の取得に対応しない世界では、番号を手動入力できます。
   名前（2文字以上）と初期画像番号を入力します。メールアドレスは任意です。
   パスワードの自動生成を選ぶと、**作成ボタンを押した時点**で原典と同じ文字集合
   `abcdefghijkmnpqrstuvwxyz23456789` から暗号学的乱数で6文字を生成します。
   自分で指定する場合は6文字を必須とし、空欄・空白・制御文字を拒否します。CP932で表現できない文字は
   原典と同じく送信時に `?` へ変換されるため、パスワードには上記の文字集合を推奨します。
   作成後の確認画面で本人がパスワードを表示して控えられます。ログや設定ファイルには保存しません。
   指定した世界に実際の作成要求を送る操作なので、接続先を確認してください。自動作成は行いません。
3. **接続** を選びます。キャラクターごとのタブで、接続・状態・地図・ログ・入力欄を個別に扱います。
4. Enterまたは **送信** で現在の行を送り、成功した行は入力欄から消します。送っていない他の行は残します。
   Shift+Enterで改行し、Ctrl+Enterまたは操作ガイドの **送信方法 > パーティーへ** でパーティーへ送信します。
   通常のEnterは、先頭の `*` を世界全体への大声に変換しません。
   大声には **Operation > 大声で発言** を使い、確認画面で送信します。
5. Tabでチャット入力欄とログのゲーム操作モードを往復します。Escでもログへ戻れます。
   文字の入力・編集中は、ゲームのショートカットより編集操作を優先します。
   メニューから行動・系統魔法・地図設定・キー操作のヘルプを開けます。
6. **Action > Write sign** で複数行の看板編集を開きます。**Send sign** は各行のあとに
   `.` を送り、**Cancel sign** は `.!` を送ります。看板の本文には、プロトコル命令の行や
   単独の終端記号を指定できません。
7. **切断** は `#x` を送ってから接続を閉じます。保存済みキャラクターを削除するときは、
   先にそのタブを閉じ、削除ボタンを再度押して確認してください。

| 矢印 / テンキー8,2,4,6 | サーバーが返した地図方式に従って移動 |
| Ctrl+移動キー | 北固定では平行移動、回転マップでは向きを変更 |

最新対象版の物理キー・IME実入力は、ユーザーによる前面化が可能になるまで残確認として扱います。

## 接続先世界の一覧

登録画面に世界一覧を表示します。狭いウィンドウでは登録欄と縦に並び、下部へスクロールできます。ゲーム中は登録欄の
**世界一覧から接続先を選ぶ** で開けます。世界名・アドレスで絞り込み、
**登録欄に入力** を選ぶと、既存 ID 登録／新規キャラ作成のサーバーと
ポートだけを入力します。名前・ID・パスワードなどは変更せず、
選択だけでは保存・ログイン・キャラ作成・世界移動を行いません。
接続には、登録後に **接続** を選びます。

wphi の原典では、同梱 `Config/unew.ini` の `Schedule15` が指定する
`http://www.tofup.net/raphi/resist.lzh` を HTTP で取得し、
展開した `resist.ini` を読みます。これはゲームサーバーへの照会ではなく、
一覧ファイルの配布です。未取得または同梱の `Date` と取得記録が違う場合に
更新し、取得できなければ前回のファイル、それもなければ同梱
`Config/worlds.ini` を使います。原典には `worlds.ini` の配布元が
見つからない旨のコメントがあります。

本アプリは起動時に外部通信をせず、保存済みの一覧、なければ原典
`d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc` の同梱一覧から
世界名・アドレス・ポートを抽出した 17 件を表示します。
**HTTP 一覧を更新** で配布元へ明示的に取得を要求できます。
原典の `Date` による自動再取得は行いません。配布 URL の変更は実行中だけ有効で、
再起動時は原典の URL に戻ります。保存済みの一覧は引き続き利用できます。
資格情報付き URL とリダイレクトは受け付けません。
取得失敗時は理由を表示し、前の一覧を保持します。

**INI ファイルから取り込む** では、既存の wphi／Philly の
`resist.ini` または `worlds.ini` のローカル絶対パスを指定できます。
原典と同様に CP932 の INI を読み、節名を世界名、`Address` をホスト、
`Port` をポートとして扱います。キーの大文字・小文字を区別せず、
不正な接続先は件数と理由を表示して除外します。全件が不正なら失敗します。
世界の説明文や資格情報は一覧として取り込みません。

HTTP の配布ファイルは 2 MiB、INI は 1 MiB までです。
LZH は Windows 標準の `tar.exe` で `resist.ini` だけをメモリーに読み、
アーカイブ内の他のファイルをディスクに展開しません。
`tar.exe` が利用できない場合はエラーを表示するため、INI から取り込んでください。
一覧は設定フォルダーの `world-directory\resist.ini` に保存されます。

一覧の配布元は平文 HTTP であり、内容の真正性や接続先の稼働・安全性は
保証されません。表示された世界へ自動接続したり、稼働確認したりはしません。
開発時の取得・選択・接続適用のテストは、所有確認済みのローカルモックだけで
行います。実ゲームサーバーへの接続は行いません。

原典の根拠：
[取得とキャッシュ](https://github.com/s7k/wphi/blob/d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc/src-tauri/src/main.rs#L415-L434)、
[HTTP/LZH と INI 解析](https://github.com/s7k/wphi/blob/d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc/src-tauri/src/download.rs#L66-L135)、
[選択による入力](https://github.com/s7k/wphi/blob/d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc/ui/src/NewCharacter.tsx#L145-L168)。

## キャラクター画像とマップチップ

素材を指定しなくても、同梱のオリジナル基本画像で地形・アイテム・キャラクターを表示します。
外部素材が読み込めた場合は、地図のmapset・アイテム・キャラクターごとに外部画像を優先します。
未設定・欠落・読み込み失敗の分だけ基本画像で補い、利用者のフォルダー指定は変更しません。
読み込みの問題は通知と「地図情報・保存」に表示します。

基本画像は `assets\bundled-basic` のオリジナル作品です。地形1枚・アイテム1枚・actor12種で
既定14コードを扱い、未知の種別はwandererを使います。外部キャラクター固有の姿を再現するものではありません。
素材専用のMIT条件・制作範囲・寸法・SHA-256は同ディレクトリの `LICENSE.txt`、`README.md`、
`manifest.json` を参照してください。パッケージにはBMP14枚とmanifest/ライセンスを入れ、
既存BMP decoderでマスク/色抜きを1回だけ適用します。制作元PNGを再度透過処理する実装ではありません。
通常/独立地図・EagleEyeと既存の倍率処理を共用します。登録候補の実画像にはこの代替画像を使いません。

**View > 画像素材フォルダー…** で、このPCにある素材フォルダーの絶対パスを入力し、**読み込む** を選びます。
**wphiが実際に配布している素材**を使う場合は、PowerShell 7.4以降で次を実行します。

```powershell
.\tools\Get-WphiGraphics.ps1
```

表示された絶対パス（既定は`.local\wphi-graphics`）をアプリで読み込みます。
スクリプトは確認済みのwphi
`d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc`を取得し、アーカイブのSHA-256を検証します。
BMPとライセンス・作者表記をそのまま取り込み、既存フォルダーへの上書きは拒否します。
Configから取り込むのは利用条件を確認した`MasterMagicMenu.xml`だけで、
公開サーバーの接続設定や他のConfigは含めません。画像の描き直しや別画像への置き換えも行いません。
既存のcheckoutを使う場合は、そのルートか`resources\phi`を指定します。
ルートを指定した場合は、その中の素材フォルダーを使います。
オフラインでは、同じ原典アーカイブを`-ArchivePath`、新しい保存先を`-OutputDirectory`へ指定できます。

寿司以外の対象キャラクター画像には、**PCGLを適用する画像部品**という範囲の指定があります。
PCGLは適用範囲の宣言とライセンスを添えたPHI対応での利用を認めており、
取り込み時には原文のPCGL両ファイルとwphiの出典READMEを保持します。
寿司画像はPCGLの対象外とされ、原典ではMIT（Copyright 2026 s7k）と指定されているため、
そのMIT表記も保持します。Mineスキンの作者は**Cress**で、wphiには2026-11-07の
保守者による再利用確認が記録されています。この確認を、スキン全体へのPCGL/MITの一括許諾とは扱いません。
これらの原典画像は外部のローカルフォルダーに置き、アプリのパッケージやソースリポジトリには同梱しません。
対象範囲と出典は`tools\WphiGraphics-NOTICE.md`を参照してください。
スクリーンショットや許可された再配布にも、これらの表記を添えてください。
別途用意した素材には、それぞれの利用条件が適用されます。

アプリの素材読み込みはローカルファイルを対象とし、画像のダウンロードやゲーム接続は行いません。
次のファイルを含むフォルダーを指定します。

```text
chara\<graphic-or-character-name>.bmp
chara\*.ali
chip\<server-mapset>.bmp
Skins\Mine\chip\Default.bmp
Skins\Mine\Chara\Index.txt
Skins\Mine\Chara\<default-graphic>.bmp
Skins\Mine\Images\Items.bmp
```

キャラクターは原典の横96pxのBMPを使います。高さ32pxの4行が背面・右・正面・左に対応し、
各行には16×32の2コマ、32×32の2コマがあります。原典の96×160の画像には最下段に
ポートレートもありますが、地図のアニメーションには使いません。
RGBが正確に`(0,128,128)`の画素を透明にし、大きい`*`のactorには32×32のコマを使います。
通常のアニメーションは500msごとに2コマを切り替えます。原典と同じく種別`0x75`も対象です。
名前を指定する`#ex-obj`では、元の下端アンカーを保って最近傍で拡大します。
その指定はactorの`O`行を受けた時点で取り込みます。

マップは1024×96のBMPを使います。左512pxには32×48のチップ32個が16列に並び、
右半分が透過マスクです。アイテムは256×64以上の横長画像で、下半分が上半分のマスクです。
マスクのRGB全成分が200を超える画素だけを不透明にします。
地形の上への張り出し、木と地面、水際、看板、アイテムと円の切り抜き、行順の重なり、
同じマスのactor位置を処理します。属性のbit 0–1で4枚の`#mapset` / `#mapset-define`を選びます。
指定されたmapsetがない場合は、その旨を表示して`Default.bmp`を使います。

描画の基準はwphi `d8f11bf60c95d470fa14ca83bcc4c02d5c83fecc`です。
既定は100%、1マス32論理pxで、物理DPIへの変換にも最近傍を使います。窓に合わせた自動縮小は行いません。
通常地図の上部には16pxの透明な余白があり、地形が欠けた部分は保持中のactorの下を黒く表示します。
クリック座標にも同じ余白を反映します。中央以外の名前はPHIタグを除き、白字に黒縁で描きます。
同じマスでは最後の空でない名前を採用し、名前一覧は同じy座標の順序を保ってy順に表示します。

EagleEyeは受信した幅・高さの大きい方を一辺とする正方形にし、不足部分を`?`で補います。
上余白は付けず、コマ0・mapset 0を使います。欄に収まらない部分はスクロールできます。
属性`0x58`は看板やアイテムではなく、名前が空・正面向き・大きい`t_man` / 種別`0x40`のactorです。
`chara\t_man.bmp`か、その種別で許可された既定画像を優先し、なければ同梱のpersonを使います。

画像の検索順は原典に従い、`.ali`の別名、画像名、キャラクター名、
`Skins\Mine\Chara\Index.txt`の種別既定画像です。`setcg`の種別`0x40`は別名より画像名を優先します。
Indexと別名ファイルはCP932で読みます。既定画像はスキンのChara、その後`chara`を探します。
別名の重複は列挙順の後勝ちで、複数ファイル間の順序は保証されません。
`LANU_`で始まる画像名は対象外です。画像変更後はフォルダーを読み直してください。
ファイルと解決済みの名前のキャッシュには上限があり、画像は8MiB・一辺2048pxまでです。

フォルダー指定は登録データの隣の`graphics-folder.txt`に保存します。
空欄で読み込むと、同梱の基本画像だけの表示へ戻ります。
欠落・破損は画面に表示します。同梱画像まで読み込めないactorに限り、
タグを除いた名前の頭文字を黄色で表示し、名前が空の場合は`?`を使います。

取得済みの原典アーカイブから、素材取り込みの検証を再実行できます。

```powershell
.\tools\Test-WphiGraphics.ps1 -ArchivePath C:\Downloads\wphi-original.zip -ArtifactDirectory C:\Temp\wphi-import-check
```

新しい成果物フォルダーを指定してください。取り込んだ全ファイルを原典アーカイブと比較し、
ライセンス・作者表記の保持、Configの許可対象がMasterMagicメニューだけであること、
改変されたアーカイブと既存フォルダーへの上書きを拒否することを確認します。

## データの保存と通信上の注意

表示名・ホスト・ポート・ランダムな資格情報キーは
`%LOCALAPPDATA%\PhiClient\characters.json`に保存します。
**設定フォルダーを開く** から、Windowsのパッケージ転送を反映した実際の保存先を確認できます。
キャラクターIDはWindows資格情報マネージャーの`PhiClient.Character`へ別に保存し、
JSONやソース管理には含めません。作成時のパスワードも保存しません。
サーバーで作成に成功したあとローカル保存だけに失敗した場合、作成済みキャラクターはサーバーに残ります。
返されたIDを既存IDの登録欄に保持するので、作成を繰り返さず保存を再試行できます。

PHIは**暗号化されていないTCP**を使います。IDや登録情報は接続先サーバーと通信経路から読み取れます。
信頼できるサーバーだけを利用してください。Windowsの資格情報保管は保存時の保護であり、
ネットワーク通信を暗号化するものではありません。

サーバーから世界移動を要求された場合は、原典と同じ
`#reserve` → `#rsv-ok` → `#trans` → `#trs-ok` → `#ch-srv-ok` の順で接続を切り替えます。
移動先に `#open` を再送せず、ログイン設定だけを送ります。別ホストへの移動はID送信前に確認し、
取り消した場合は移動先へ接続しません。失敗時は元世界の未処理行を順序どおり処理します。
移動中の操作や、古い世界で確認待ちになった操作は新しい世界へ持ち越しません。
成功後は同じ登録キャラクターの接続先を保存します。保存に失敗した場合も実際の移動は取り消されないため、
画面のエラーを確認してからアプリを終了してください。

ログはネイティブの `RichTextBlock` で表示します。PHI の色・文字サイズ・フォント・太字・
斜体・下線・上線・取消線・改行・タグの終了を解釈し、元のタグ付き行と受信時刻を別に保持します。
過去ログへスクロールすると新着への追随を一時停止し、右下に **最新へ ↓** を表示します。
ボタン、または手動スクロールで末尾へ戻ると追随を再開します。ボタンはキーボードでも操作できます。
閲覧位置はキャラクター・内緒話の相手ごとに保持し、折返しや画像の遅延表示でも同じ本文を基準に戻します。
表示上限で閲覧中の行が削除された場合は、残っている先頭へ移ります。
**Operation > Follow latest log** を無効にした場合、**最新へ ↓** は一度だけ末尾へ移動し、
自動追随の設定は変更しません。設定を再び有効にすると末尾へ移って追随します。
発言本文のタブは原典の変換後の桁数で8桁ごとに展開し、半角空白2個を全角空白1個で表示します。
`img_wnd` がある行は画像化とリンク化を抑え、宛先の `to=` と空タグは表示用の制御情報として扱います。
右クリックの **行全体をコピー** / **行全体を入力欄へコピー** は、部分選択でも行全体を使います。
タグ・時刻・名前の除去やタグの無効化は設定に従います。入力欄へのコピーだけでは送信しません。
画像タグと画像URLは、設定の **ログの画像を表示する** が有効なら取得してログ内へ表示します。
URLのリンク化、画像URLの画像化、元URLの追記、大声の画像・大きい文字、未知のタグの表示を
個別に設定でき、Philly.iniの同名設定も取り込めます。画像タグのwidth/heightは原典と同じ
0〜1000、数値以外は0として扱います。両方を指定した場合は指定した縦横比で表示します。
取得は公開HTTP/HTTPSへ限定し、名前解決したIPを検査してそのIPへ接続します。
資格情報付きURL、ローカル・非公開IP、転送、proxy、cookieを使用する通信は行いません。
1画像1MiB・5秒・1048576画素、同時取得2件、アプリ起動中16画像までとし、
待機・失敗・上限は画像の位置に表示します。PNG/JPEG/GIF/BMPを扱います。
GIFはnativeの連続表示を使い、読み込み時のWindowsのアニメーション設定を反映します。
GIFにはさらに64コマ・論理キャンバス全コマ合計4194304画素の上限を設け、
超えた場合は理由を表示します。コマの合成・透明部分・表示間隔はnativeデコーダーが扱います。
画像キャッシュは終了時に解放し、HTML保存では外部画像の代わりに`[画像]`を記録します。
サーバーが送ったHTMLは文字として表示し、実行しません。外部リンクは確認後に
ブラウザーで開きます。ローカル・非公開アドレスは拒否しますが、外部ブラウザーの通信まで
アプリが固定・制御するものではありません。

**Operation > このキャラクターのログを自動保存** で、タブ単位の自動保存を切り替えます。
起動時は保存しません。有効にしてからの行を `Logs\<キャラクター名>\<日付>.html` に追記し、
設定で HTML 保存を無効にした場合は `.txt` に追記します。自動保存には表示設定にかかわらず
時刻を付けます。**ログ欄の内容をHTMLに保存** は現在の表示履歴を別ファイルへ保存します。
**ログの保存先を開く** で保存先を開けます。書き込み失敗はログへ表示し、自動保存を停止します。

ウィンドウを閉じると、接続を終了し、処理中の設定・接続先更新・ログ・記録地図の保存を待ちます。
自動保存に失敗した行は、終了前に `LogBuffer-<ランダム名>.html` へ保存して保持します。
その保存や記録地図の保存に失敗した場合は画面とメモリ上の記録を保持します。
画面上部の案内で保存先を確認し、問題を解決してからウィンドウを閉じ直してください。
この終了フローはウィンドウの閉じる操作に対応します。プロセスの強制終了・PCの電源断では
処理中の書き込みを完了させられません。
保存した HTML からもスクリプトや画像を自動取得・実行しない制限を付けています。

接続はCP932・LF区切りで、接続期限10秒・送信期限30秒、受信1行64KiBまでです。
超過した行は次のLFまで破棄し、理由を表示します。2分間受信がない場合はkeepaliveを開始し、
3分で警告します。literalの`#more`本文以外では`#lag`と`#remap`へ自動応答します。
表示履歴は2,000行・rawテキスト2MiBまで、各行のplain表示は8,192文字までです。
その履歴上限内では、装飾表示とコピー用に元の行を保持します。

## 実装範囲と残る確認

登録・新規作成、資格情報を分けた保存、キャラクターごとのnativeタブ、メニュー、
複数行・現在行・Party入力、HP/MPバーと状態名、7×7と旧5×5の地図、EagleEye、
外部素材の描画、フルキー移動と主要操作、系統魔法の準備、ページ付き選択リスト、
確認ダイアログ、看板編集を実装しています。

今回の互換性監査で、設定の保存・元のINI取り込み、F8–F12 / Alt+G、対象魔法の再装備、
50–400% の倍率、方位表示、世界別の地形記録、移動予測、滑らかな移動、
reserve/trans による世界移動、原典のパスワード生成とログ装飾・コピー・保存を追加しています。
全体の実UI確認はまだ進行中です。

**File > 全タブを接続／全タブを切断／全タブを強制切断** は、原典と同じく
現在開いているタブのキャラクターを対象にします。全タブを接続すると、切断済みのタブだけを
再接続し、タブと入力を保持します。保存済みの別のキャラクターは、個別にタブを開いて使います。
通常の切断は接続中の世界へ `#x` を送り、強制切断は通信を直接終了します。
`Alt+Pause` も全タブの強制切断です。

発言はカーソルのある行だけを送信し、成功した行を入力欄から消します。
原典に合わせた送信済み行の保持から、チャットとして使いやすい動作へ変更しています。
最後の行を送ると、その行は空欄か設定済みの発言prefixになり、未送信の行は残ります。
確認取消・送信失敗・IME確定だけのEnterでは消しません。送信中に編集した新しい下書きも保持します。
通常の発言では先頭の `*` を原典どおり保護し、
明示的に大声を選んだ場合は元の行へ `*` を付けます。

**Character > priv（内緒話）** で、その世界の相手一覧と内緒話の画面を開きます。
相手を選んで会話を開くと、入力欄の Enter または **内緒話を送信** で送信できます。
会話は参加者の組ごとに分かれ、受信した内緒話は通常のログにも残ります。
受信タグから作られた多人数の会話では、最初に返信する前に全員の名前を確認します。
キャンセル・送信失敗時は入力を保持します。番号が見つからない相手は明示し、
見つかった相手だけに送信します。内緒話の行を入力欄へコピーする操作は、
通常の発言欄ではなく内緒話の入力欄を対象にし、コピーだけでは送信しません。

相手一覧は `#ulist` で取得します。並行する取得はまとめ、10秒以内は直近の一覧を使います。
最後の `#user` 受信から300ms待ち、最大60秒で取得を終えます。返事がない場合はエラーを
表示します。世界移動・切断で取得を中止し、別の世界へ古い内緒話を送信しません。
会話は最大50組、各組の履歴は最大2,000行・2MiBです。安全のため宛先は1,000人、
一度の送信量は8Mi文字相当までに制限しています。

**File > 超魔法のXMLを読み込む…** から、信頼できるwphi／Phillyの
`Config\MasterMagicMenu.xml` を指定できます。Shift_JIS / CP932、またはBOM付きUTF-8を
読み込み、指定したファイルの参照を保存します。起動時はアプリ保存先の
`MasterMagicMenu.xml`、保存済み参照、素材フォルダーの `Config\MasterMagicMenu.xml` の順に探します。
原典の素材取り込みスクリプトは、許可記録を確認したこのXMLだけをConfigから追加します。
原典READMEに記録された2026-11-09のPhilly作者による同梱許可と出典を保持し、
公開世界の接続設定や他のConfigファイルは取り込みません。既存の素材フォルダーへの上書きも拒否します。

**超魔法** メニューは経験値が原典のマスター値 `99999999` のキャラクター、または
設定で表示を有効にしたキャラクターに表示します。選んだ項目の送信・確認・整数・文字入力を
XMLの順番どおりに実行します。表示設定はメニューの切替であり、実行結果は接続先の権限と仕様によります。
整数は半角の数字と先頭の `-`、文字は `%string`、整数は `%int` として置換します。
取消・不正な整数・世界移動・切断で残りの手順を中止します。送信済みの操作は取り消されません。
実行中の手動送信を止め、元の接続世代に固定して、古い手順が移動先へ流れないようにしています。
XMLは1MiB、項目は2,048件、手順は1項目4,096個までです。DTDと外部entityは読み込みません。
超魔法の実UI総合確認は、全体の回帰確認とあわせて進行中です。

確認中の範囲には、旧5×5 actorの実UIでの全組み合わせ、物理キー・IME、
正常WAVの実音、前面／背面通知、別DPI間のドラッグと高コントラストがあります。
更新確認は自製品のGitHub Releasesを対象に実装済みで、公開APIへの実通信は未確認です。
従来この節で残差としていた他スキンとactor状態装飾は、対象原典も再確認しました。
原典の`assets.rs:36–37`はMine固定で、`drawMap.ts:262–305`も状態値による画像装飾を行いません。
状態値の受信・保持と状態表示は、画像装飾とは分けて扱います。これはwphiの拡張機能を
要件から除外する判断ではなく、対象原典にある動作との照合結果です。
生のコマンドを送れることを、対応するクライアント UI の実装済みとは扱いません。

リストは番号のない説明行も保持し、原典と同じく先頭行から決めた番号のずれと行順で選択します。
続きの先頭番号が前ページの最後と一致する場合だけページを結合します。
続きがない場合や読み込み待ちの場合の `9` は送信しません。空の完了リストは既存の表示を
消さず、明示的なリスト終了で閉じます。

## 構成と検証

- `PhiClient.Core\ClientModel.cs`、`GameModel.cs`: UIを含まない状態、型付きメッセージ、純粋なUpdate。
  選択リストの更新は元の状態を変更せず、新しい状態を返します。
- `PhiClient\App.cs`、`App.Game.cs`: ReactorのView。
  `App.State.cs`で実際の`ClientModel`を公式`UseReducer`へ接続しています。
- `App.Effects.cs`、`App.Input.cs`、`App.GraphicsEffects.cs`、`App.Dialogs.cs`:
  起動・通信・物理キー/IMEのアダプター、素材設定、nativeダイアログ。
  非同期処理の結果は型付きメッセージで返します。
- `CharacterStore`、`GraphicsStore`、`GameSession`: Windowsへの保存、上限付きのローカル素材読み込み、
  タブごとの実行時ハンドル。接続・bitmap・controlはCoreのModelに入れず、
  Viewや純粋Updateからファイルを読みません。描画前に画像を準備し、native bitmapとして渡します。
- その他の`PhiClient.Core`: 通信、行分割、解析、キーの対応、OSに依存しない画素合成。
  `MapPresentation.cs`はEagleEye・名前/頭文字・クリック座標の純粋な変換、
  `App.MapEffects.cs`はnative bitmapとDPIのライフサイクルを担当します。
- `PhiClient.Core.Tests`: 所有loopbackモックと純粋テスト。実ゲームサービスは使いません。

`dotnet test`で、ログインの送受信、分割CP932、literal看板、地形とactorのbyte解析、
リスト番号、制御応答、64KiBの行境界、不正な送信行の拒否、登録成功・拒否、
キーの優先順位、CR/LF付き現在行、ページ選択、魔法準備、マスク・重なり、
過去の状態を変更しない更新とタブの独立性を確認します。
水際は独立8bitの全256通りと4象限を、別に書き起こした期待値表と照合します。
合成素材のfixtureは数値仕様の確認であり、実素材との見た目の一致を証明するものではありません。
native packaged試験は所有loopbackだけへ接続し、合成素材の試験と、
利用条件に従って外部取り込みした実wphi素材の表示確認を分けて記録します。
公開サーバーとの相互運用、ARM64実行、高コントラスト、今回対象版の物理キー・IME、
別DPI間の実ドラッグ等には残確認があります。これらをUIAや純粋テストの合格で置き換えません。

Microsoft.UI.Reactor preview.17では、画面を切り替えたあと設定項目がnative UIAの列挙から
消える事象を確認しました。主窓の`ReactorHost.Reconciler.Pool.Enabled`だけを
公式の公開`configure` APIで無効にすると、幅変更後の設定保存を含む9項目が合格しました。
独立地図窓は別のhostとpoolを持ち、今回の修正では変更していません。
poolの無効化には新規controlの割り当てが増える可能性があり、性能ベンチマークは行っていません。
ReflectionやReactorの非公開API、同名の代替実装は使っていません。
