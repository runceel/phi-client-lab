# Issue and pull request workflow

- Track each independent problem in one issue and its corresponding pull request.
  Do not combine unrelated problems in the same issue or pull request.
- Make dependencies between issues and pull requests explicit, including the
  order in which they must be completed.
- Close an issue only after implementation and the necessary verification are
  complete and the change is confirmed on `main`.
- Do not close unresolved or unverified issues merely to reduce the issue count.
